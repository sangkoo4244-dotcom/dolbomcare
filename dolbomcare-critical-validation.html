5.2 의료 연계 (HL7/FHIR)의 현실

문제: 국내 병원 시스템이 HL7를 지원하는가? - 대학병원: HL7 v2 지원 (일부) - 일반 병원: 대부분 레거시 시스템 (10년 이상 된 독자 시스템) - 의원급: 거의 지원 안 함 - → 실제 통합 가능 병원: 10-15% (대학병원 중심) 결과: - 우리의 "의료 연계" 기능은 파일럿 단계에서는 거의 사용 불가 - 데이터 통합은 수동 방식 (API 아닌, 파일 업로드 등) - 차별화 지점이 아니라 "미래 로드맵" → MVP에 포함하면 안 됨 (개발 시간만 낭비)

5.3 AI 기반 케어 예측: MVP에서 제외된 이유가 맞다

긍정적 평가: - "AI 기능 제외"는 현명한 결정 - 데이터 부족 (초기 50개 센터 × 3개월 = ~5,000 케어 기록) - 의미 있는 예측 모델 불가능 하지만 장기 전략 문제: - 1년 후 (100개 센터)까지도 데이터 부족 가능 - AI 모델 개발 18-24개월 필요 - 즉, AI는 2028년 중반 가능 → 경쟁사 (케어링)의 AI 시간 벌어줄 위험

6️⃣ 현실성이 가장 낮은 부분 TOP 5

1️⃣ 고객 획득 속도 (위험도: 🔴 극심)
  • 계획: 6개월 50개, 12개월 100개
  • 현실: 6개월 10-15개, 12개월 30-50개 더 현실적
  • 이유: CAC 높음, 기존사 경쟁, 규제 불확실성
  • 영향: 매출 목표 미달성 → 자금 부족 → 실패 가능성
2️⃣ PIMS 인증 일정 (위험도: 🔴 극심)
  • 계획: 12-15개월
  • 현실: 18-24개월 (규제 불확실성, 전문가 부족)
  • 영향: 고객 확보 지연 + 매출 부족 + 자금 소모
  • 최악 시나리오: 인증 실패 → 재신청 (추가 6-12개월)
3️⃣ 팀/자금 현실성 (위험도: 🔴 극심)
  • 필요: 300억원 + 경험 있는 8명 팀
  • 현실: 경험 있는 인재 확보 어려움, 투자자 설득 어려움
  • 영향: 프로젝트 시작 자체가 어려울 수 있음
4️⃣ 차별화 지점의 일시성 (위험도: 🟠 높음)
  • 우리의 기술: 12-18개월이면 경쟁사가 따라할 수 있음
  • 특허 불가: HL7/FHIR는 개방 표준
  • 데이터 우위: 3-5년 후 경쟁사도 데이터 축적
  • 결과: 5-7년 후 경쟁 심화 → 가격 인하 압박
5️⃣ 규제 리스크의 불확실성 (위험도: 🟠 높음)
  • 원격 모니터링의 법적 지위 미정 (2026년 현재)
  • 정부 방침 변화: PIMS 요구 강화 가능성
  • 고객 이탈: 법적 리스크 이유로 서비스 취소 가능
  • 결과: 예측 불가능한 외부 충격

7️⃣ 현실적인 대안 제시

대안 A: "Lean MVP" 접근법 (추천)

개념: 의료 연계 없이, 기본 기능에만 집중
  • 핵심 2개 기능 (의료연계 제외) - 요양사 관리 + 기본 기록 (웹 + 모바일) - 보호자 앱 (기본 조회만)
  • 개발 기간: 3-4개월 (6개월이 아님)
  • 비용: 현재의 40-50% 수준 (10-15억원)
  • 초기 고객: 10-15개 센터 (50개 아님)
  • PIMS: MVP 단계는 제외, Phase 2부터 (2027년)
장점: - 더 빠른 시장 진입 (3-4개월) - 초기 고객 피드백 기반 개선 (6개월 낭비 방지) - 자금 부담 50% 감소 - "의료 연계는 고객이 원하는가?" 검증 가능 위험: - MVP가 너무 기본적일 수 있음 (고객 만족도 낮을 수 있음) - 경쟁사와의 기능 차이 (하지만 초기엔 중요하지 않음)

대안 B: "특정 틈새 공략" (검토)

개념: 전체 시장이 아닌, 특정 고객군에 집중
  • 타겟 세그먼트 - 소규모 센터 (10-30명) → "기술 도입에 긍정적인 센터" - 또는 특정 지역 (서울 강남) → "높은 수용도"
  • 고객 확보 전략 - 입소문 + NPS 높음 (대량 판매 아님) - 초기 3개 센터: "성공 사례" 만들기 - 다음 1년: 입소문으로 30-50개 (현실적)
  • 가격 프리미엄: 작은 기업이 "높은 만족도"로 프리미엄 가능
장점: - 경쟁 강도 낮음 (케어링은 대규모 중심) - 고객 만족도 높음 (니즈 맞춤) - 입소문으로 성장 (영업비용 낮음) 위험: - 성장 속도 느림 (대량 판매 불가) - 투자자 입장에서 "너무 작은 목표"로 보일 수 있음

대안 C: "B2B2C" 파트너십 (검토)

개념: 직접 고객 확보가 아닌, 기관/협회를 통한 접근
  • 파트너 - 대한요양보호사협회 (40만 회원) - 전국요양시설협회 (회원 센터 많음) - 대형 의료기관 네트워크
  • 모델: "협회 회원 할인 제공 (10-20% 인하)"
  • 고객 확보 비용: 현재의 30-40% 수준
  • 신뢰도: 협회 추천 → 고객 신뢰도 높음
장점: - CAC 70% 감소 - 신뢰도 증가 (협회 추천) - 초기 고객 확보 빠름 위험: - 협회와의 협상 능력 필요 - 협회가 원하는 것 (교육, 데이터)과 우리 방향 차이 가능 - 협회의 이해관계 충돌

🎯 최종 권고사항

지금 바로 해야 할 것 (우선순위) 1️⃣ 고객 검증 (1-2개월) - 센터장 20명 인터뷰 → "정말 필요한 기능"이 무엇인지 확인 - 요양사 20명 인터뷰 → 독립성/수입 투명성 수요 검증 - 보호자 20명 인터뷰 → "신뢰" 기능의 우선순위 파악 - 결과: ARPU 목표 재설정, 기능 우선순위 변경 가능 2️⃣ PIMS/규제 컨설팅 (2-3개월) - PIMS 전문 컨설턴트 상담 (최소 3개 회사) - 실제 인증 기간, 비용, 일정 확인 - "인증 없이도 파일럿 가능한가?" 법적 검증 3️⃣ 팀 구성 가능성 평가 (2개월) - 의료시스템 경험 있는 CTO 접촉 (5-10명) - PIMS 전문가 영입 가능성 파악 - 현실적 급여 범위 설정 4️⃣ 파일럿 고객 확보 (3개월) - 3-5개 센터와 협의 (무료 파일럿, 3-4개월) - 성공 메트릭 합의 (NPS, 완성도, 만족도) - 초기 피드백 기반 로드맵 수정 전체 검증 기간: 3-4개월
GO/NO-GO 판단 기준: ✅ GO (투자 진행): - 고객 인터뷰 NPS 40 이상 - PIMS 인증 기간 확정 (18개월 이하) - CTO 급 인재 확보 약속받음 - 초기 투자 30-50억원 확보 가능 ❌ NO-GO (프로젝트 중단/방향 변경): - 고객 인터뷰 NPS 30 이하 - PIMS 인증 기간 24개월 이상 - 투자자 설득 실패 (30억원 미만) - 핵심 팀 구성 불가능

최종 메시지: "시장 기회는 크다. 하지만 현재의 계획은 낙관적이다. 고객 검증과 현실적 평가 없이 진행하면 실패 확률이 높다. 3-4개월 검증 기간을 통해 가정을 검증한 후 GO/NO-GO를 판단하기를 권장한다."
