청구 입력 도우미

홈 › 청구·급여 › 청구 입력 도우미
사용자
센터장
공단 장기요양정보시스템에서 방문요양을 청구할 때 [급여내용 자료관리]에 입력할 내용을 이용자별·일자별로 공단 화면 순서대로 모았습니다. 돌봄케어는 공단에 전송하지 않습니다. 공단 화면에서 청구서를 생성하고 청구서 전송까지 누르는 것은 센터가 직접 합니다.
요양요원 전송내역›서비스내용 입력› 급여내용 자료관리 (이 화면이 돕는 곳)›청구명세서 조회›청구서 전송

공단 화면에서 직접 확인할 것

돌봄케어에 없는 정보입니다. 공단 [서비스내용 입력]·[특정내역등록]에서 확인하거나 입력하세요.
가족관계(친족 여부)
가족요양보호사 여부는 돌봄케어에 기록하지 않습니다. 공단 급여계약 통보 내용이 기준입니다.
원거리교통비·가산
원거리교통비, 종일방문요양 가산, 인지활동형 방문요양 가산은 공단 화면에서 선택합니다.
2인 요양보호사 제공사유
같은 이용자에게 시간이 겹치는 방문이 있으면 "확인"에 표시됩니다. 실제로 2인이 제공했다면 사유를 입력합니다.
120분 미만 제공사유
공단 특정내역에 사유 칸이 있습니다. 해당 여부는 고시에서 확인하세요(이 화면은 표시하지 않습니다).
간호(조무)사 방문
돌봄케어에 기록하지 않습니다.
청구서 작성인
청구할 때마다 기관 대표자가 직접 입력해야 합니다. 청구서 생성 후 전송까지 눌러야 청구가 끝납니다.
근거: 공단 「급여비용 청구 업무 바로알기」(2021.12 기준). 공단 화면이 개편됐을 수 있어 화면 구성은 다를 수 있습니다.
