사용자
메뉴별 사용법
돌봄케어를 처음 쓰는 요양보호사와 센터장이 누가 무엇을 하면 어디로 이어지는지, 그리고 메뉴마다 무엇을 하는 곳인지 정리했습니다. 기본 사용 순서는 "사용 안내"(요양보호사) / "센터장 안내"에서 단계별로 볼 수 있습니다.
요양보호사 사용 안내 센터장 안내

① 업무 흐름: 요양보호사 → 센터장으로 이어지는 과정

단계요양보호사가 하는 일센터장 화면에서는이어지는 결과
1. 일정 잡기요양보호사가 방문 계획 제안 (또는 센터장이 반복 방문 등록)센터장 방문계획 승인 → 승인요양보호사 "나의 일정"에 확정 + 알림
2. 방문하기요양보호사가 도착·퇴실 누르기센터장 대시보드 "오늘의 방문", 요양보호사별 현황도착 안 누르면 "도착 미기록" 표시
3. 기록하기요양보호사가 음성 기록 저장센터장 방문 기록 현황에 표시 + 청구 자동 생성(작성중)계획과 맞으면 항목이 미리 채워짐
4. 제출·승인요양보호사가 나의 청구에서 제출센터장 청구관리에서 승인 또는 반려반려하면 요양보호사에게 사유와 알림
5. 정산·급여(요양보호사는 할 일 없음)센터장 본인부담금 수납 → 월별정산 확인 → 급여 확정요양보호사 "나의 급여"에 명세
6. 수시일정 변경 요청, 사고 보고, 인수인계, 이용자 정보 변경 요청센터장 방문계획 승인 / 사고·인수인계 / 이용자관리에서 처리대시보드 "우선 처리 업무"에 건수로 표시
핵심: 요양보호사가 음성 기록을 저장하고 "나의 청구"에서 제출해야 센터장이 승인할 건이 생깁니다. 센터장이 승인하지 않으면 정산·급여에 반영되지 않습니다.

② 메뉴별 사용법

대시보드 열기

어떤 화면
오늘 방문 건수와 내가 해야 할 일을 모아 보여 주는 첫 화면입니다.
언제
출근해서 가장 먼저, 퇴근 전 한 번 더.
하는 일
오늘의 방문, 기록 안 쓴 방문, 반려된 청구를 확인하고 눌러서 바로 이동합니다. 처음에는 "처음 시작하기" 체크 목록이 나옵니다.
연결
여기 숫자는 다른 화면에서 쓴 것이 모인 결과입니다. 여기서 따로 입력하는 것은 없습니다.

알림 열기

어떤 화면
센터장 승인·반려, 기록 요청, 보호자 메시지가 도착하는 곳입니다.
언제
하루 2~3번, 또는 휴대폰 알림이 왔을 때.
하는 일
반려 알림은 사유가 들어 있습니다. 눌러서 해당 화면으로 이동해 고칩니다.
연결
센터장이 승인·반려·일정 변경 승인을 하면 여기로 옵니다.

나의 일정 열기

어떤 화면
달력과 날짜별 방문 목록입니다. 날짜를 누르면 그날 일정이 시간순으로 나옵니다.
언제
방문 전날 확인, 방문 때 "도착/퇴실".
하는 일
도착·퇴실 누르기, + 방문 계획 제안, 예정 일정의 일정 변경 요청(새 시간·서비스·항목과 사유).
연결
제안·변경 요청은 센터장의 방문계획 승인으로 갑니다. 승인 전에는 기존 일정이 유지됩니다. 도착·퇴실은 센터장 대시보드에 바로 반영됩니다.

음성 기록 열기

어떤 화면
방문 후 제공한 서비스와 이용자 상태를 말로 또는 글로 기록하는 곳입니다.
언제
방문이 끝난 직후, 당일 안에.
하는 일
이용자 선택 → 제공한 항목 체크 → 상태·변화 선택 → 저장. 오늘 승인된 계획의 항목과 시간이 미리 채워지고, "지난 방문과 같게 채우기"도 있습니다.
연결
저장하면 청구가 자동으로 만들어집니다(작성중). 센터장 "방문 기록 현황"에도 바로 보입니다. 계획 시간대 밖이면 "계획 외"로 표시됩니다.

나의 청구 열기

어떤 화면
내 방문 기록으로 자동 생성된 청구 목록입니다.
언제
음성 기록을 쓴 날, 그리고 반려 알림을 받았을 때.
하는 일
작성중 건을 확인하고 제출합니다. 반려된 건은 사유를 보고 고친 뒤 다시 제출합니다.
연결
제출하면 센터장 청구관리의 "검토 중"으로 올라갑니다. 제출하지 않으면 센터장 승인 대상이 되지 않습니다.

인수인계 열기

어떤 화면
담당이 바뀌거나 교대할 때 이용자 상태·주의사항을 남기는 메모입니다.
언제
담당 변경·휴가 전, 또는 새로 맡았을 때.
하는 일
이용자와 받는 요양보호사를 정해 내용을 남기고, 받는 사람은 읽고 "확인"합니다.
연결
확인하지 않은 인계 메모 건수는 센터장 대시보드에 나타납니다.

사고·응급 보고 열기

어떤 화면
낙상·욕창·투약 사고·응급 이송이 생겼을 때 경과와 조치를 기록하는 곳입니다.
언제
사고가 생기면 119 등 응급 조치를 먼저 하고, 안정된 뒤 바로.
하는 일
이용자·발생일·사고 유형·경과·조치를 적어 보고합니다.
연결
센터장에게 알림이 가며, 센터장이 보호자 통보일과 재발방지 대책을 이어서 적습니다.

나의 급여 열기

어떤 화면
이번 달 근무시간·방문 횟수와 예상 급여, 확정된 급여명세입니다.
언제
월말·월초.
하는 일
확정된 급여명세를 보고 PDF로 저장합니다. 금액이 다르면 센터에 문의합니다.
연결
센터장이 급여 확정을 하면 명세가 이곳에 나타납니다. 확정은 지급 완료와 다릅니다.

담당 이용자 열기

어떤 화면
내가 맡은 이용자 목록과 상세 정보입니다.
언제
처음 맡을 때, 방문 전 확인할 때.
하는 일
이용자 정보를 보고, 주소·보호자 연락처 같은 일상 정보는 직접 고칩니다. 등급·서비스 종류처럼 청구에 영향을 주는 정보는 변경 요청을 보냅니다.
연결
변경 요청은 센터장이 승인해야 반영됩니다.

보호자 소통 열기

어떤 화면
이용자 보호자와 센터가 주고받는 메시지입니다.
언제
보호자 알림이 왔을 때.
하는 일
이용자를 선택해 메시지를 확인하고 답합니다. 응급은 메시지 말고 전화합니다.
연결
모든 대화는 센터에 기록되어 센터장도 볼 수 있습니다.

사용 안내 열기

어떤 화면
처음 쓰는 요양보호사를 위한 단계별 안내입니다.
언제
처음, 또는 헷갈릴 때.
하는 일
1~8단계를 따라 하면 하루 업무가 끝납니다.
연결
-

대시보드 열기

어떤 화면
처리할 건이 모인 첫 화면입니다. "우선 처리 업무"와 요양보호사별 현황이 있습니다.
언제
출근 직후 3분, 퇴근 전.
하는 일
건수가 있는 항목을 눌러 해당 화면으로 이동해 처리합니다.
연결
요양보호사가 올린 것이 이곳 숫자로 모입니다. 여기서 따로 입력하는 것은 없습니다.

방문계획 승인 열기

어떤 화면
요양보호사가 제안한 방문 계획과 일정 변경 요청 카드가 오는 곳입니다.
언제
매일. 변경 요청은 알림이 오면.
하는 일
계획 승인·반려(반려는 사유 필수), 일정 변경 승인·반려, 반복 방문 일괄 등록.
연결
승인하면 요양보호사 "나의 일정"에 확정됩니다. 변경 승인 시 기존 일정이 새 날짜·시간·서비스로 바뀝니다.

방문 기록 현황 열기

어떤 화면
요양보호사가 쓴 기록을 센터 전체로 모아 보는 화면입니다(상태별 카드).
언제
매일 훑어보기, 누락 확인.
하는 일
기록을 확인하고, 필요하면 센터장이 대신 입력합니다. 승인은 여기서 하지 않고 청구관리에서 합니다.
연결
같은 기록이 청구관리에서는 "청구"로 보입니다(같은 데이터의 다른 화면).

공단 태그 대조 열기

어떤 화면
공단에서 내려받은 전자태그 전송내역 파일을 돌봄케어 기록과 맞춰 보는 화면입니다.
언제
공단 청구 전(월 1~2회), 태그 오류가 의심될 때.
하는 일
롱텀에서 받은 엑셀(.xlsx)/CSV를 올리고, 수급자·시작 시각 열을 지정한 뒤 대조하기. "태그 없음", "시간 확인", "계획 없음"을 확인합니다.
연결
올린 파일은 저장하지 않습니다. 공단과 연결하거나 인증서를 쓰지 않으며, 돌봄케어의 방문 계획·도착 기록과 비교만 합니다.

인수인계 열기

어떤 화면
요양보호사 간 인계 메모 현황입니다.
언제
담당 변경 때, 미확인 건이 있을 때.
하는 일
미확인 인계를 확인하고, 담당 변경 시 인계를 남기게 안내합니다.
연결
평가에서 담당 변경 후에도 서비스가 이어졌음을 보여 주는 기록이 됩니다.

사고·응급 보고 열기

어떤 화면
사고 보고 목록과 보완 현황입니다.
언제
사고 알림이 왔을 때, 대시보드에 "보완 필요"가 있을 때.
하는 일
보호자 통보일과 재발방지 대책을 입력해 보고를 완성합니다.
연결
요양보호사가 쓴 경과·조치에 이어서 센터장이 적는 구조입니다.

청구관리 열기

어떤 화면
청구를 승인·반려하는 중심 화면입니다.
언제
매일, 월 마감 전 반드시.
하는 일
검토 중 청구의 방문 내용을 보고 승인 또는 반려(사유 필수), 일괄 승인. "⚠ 확인 표시"(계획 외·도착 미기록·제공 시간 초과)를 먼저 봅니다.
연결
승인된 청구가 본인부담금·월별정산·급여 확정·수익분석의 기준이 됩니다.

본인부담금 열기

어떤 화면
이용자별 본인부담금과 수납 현황입니다.
언제
월초 청구 후, 수납할 때.
하는 일
수납 여부만 입력합니다(금액은 승인된 청구에서 자동 계산). 연말정산용 납부확인서 출력.
연결
청구를 승인하면 자동으로 집계됩니다. 금액을 따로 입력하지 않습니다.

월별정산 열기

어떤 화면
월별 청구·정산 현황을 요양보호사별·서비스별로 보는 화면입니다.
언제
월 마감.
하는 일
조회하고 엑셀로 내려받아 확인합니다. 입력 항목은 없습니다.
연결
청구관리에서 승인한 데이터를 모아 보여 줍니다.

급여 확정 열기

어떤 화면
요양보호사별 급여를 확정해 명세로 잠그는 화면입니다.
언제
월 마감 마지막 단계.
하는 일
월을 선택해 요양보호사별 금액을 확인하고 확정합니다. 되돌릴 수 없으니 검토 중 청구가 남았는지 먼저 봅니다.
연결
확정하면 요양보호사 "나의 급여"에 명세가 나타납니다.

수익분석 열기

어떤 화면
기간·서비스·이용자별 수익을 분석하는 화면입니다.
언제
월 마감 후, 경영 점검 때.
하는 일
조회와 엑셀 내려받기만 합니다. 입력 항목은 없습니다.
연결
승인된 청구 기준입니다.

이용자관리 열기

어떤 화면
이용자 등록·수정·조회와 제공기록지 출력, 정보 변경 요청 승인을 하는 곳입니다.
언제
신규 이용자 등록 때, 변경 요청이 올 때, 서류 출력할 때.
하는 일
이용자 등록(주소 검색 포함), 담당 요양보호사 지정, 요양보호사의 변경 요청 승인·반려, 제공기록지 출력.
연결
담당 요양보호사로 지정되어야 그 요양보호사의 "담당 이용자"에 나타납니다.

보호자 관리 열기

어떤 화면
보호자 가입 초대와 승인 화면입니다.
언제
새 보호자를 연결할 때.
하는 일
이용자를 골라 초대 코드를 발급해 전달하고, 가입 신청을 승인합니다.
연결
승인된 보호자는 해당 이용자의 방문 기록을 볼 수 있고 "보호자 소통"으로 연결됩니다.

보호자 소통 열기

어떤 화면
보호자와의 메시지입니다.
언제
보호자 알림이 왔을 때.
하는 일
이용자별로 메시지를 확인하고 답합니다.
연결
요양보호사와 같은 대화에 센터장도 참여합니다.

급여제공계획 · 상담 기록 · 결과평가·사례관리 · 교육·안내 기록 열기

어떤 화면
공단 평가에서 확인하는 서류를 기록하는 4개 화면입니다.
언제
평가 대비로 정기적으로(상담은 월 1회 등).
하는 일
급여제공계획서 작성과 공단 통보일 기록, 월 상담 기록, 결과평가·사례관리 회의, 직원 교육·보호자 안내를 기록합니다.
연결
욕구사정·낙상·욕창·인지 평가가 계획서에 자동 반영되고, 평가 준비 자료에 모입니다. 공단 통보는 장기요양정보시스템에서 직접 하고 날짜만 기록합니다.

평가 준비 자료 열기

어떤 화면
평가 때 보여 줄 기록을 이용자·기간별로 모아 인쇄하는 화면입니다.
언제
공단 평가 전.
하는 일
이용자와 기간을 고르고 "자료 모으기" → 인쇄. 새로 입력하는 것은 없습니다.
연결
위 서류 화면과 방문 기록에서 자동으로 모입니다.

직원관리 열기

어떤 화면
직원 계정과 자격증·근로 기록을 관리합니다.
언제
신규 입사·퇴사 때.
하는 일
직원 계정 추가(이메일·초기 비밀번호), 비밀번호 재설정, 자격증·근무 상태 관리.
연결
추가한 요양보호사는 이용자의 담당으로 지정해야 업무가 시작됩니다.

센터 정보 열기

어떤 화면
센터 이름·주소·전화번호·제공 서비스를 관리합니다.
언제
처음 한 번, 정보가 바뀔 때.
하는 일
기본 정보 입력, 센터 찾기 공개 여부 설정, 알림톡 사용 현황 확인.
연결
보호자에게 보이는 센터 정보와 센터 찾기에 쓰입니다.

센터장 안내 열기

어떤 화면
센터장을 위한 업무 흐름 안내입니다.
언제
처음, 또는 월 마감 때.
하는 일
매일 3분·월 마감 순서를 따라 합니다.
연결

③ 중복·이중 작업 점검 결과

항목판정설명
이용자·시간 입력자동 연결방문 계획이 있으면 음성 기록의 제공 항목·제공 시간·서비스 유형이 미리 채워집니다. "지난 방문과 같게 채우기"도 있습니다.
청구서 작성별도 입력 없음음성 기록을 저장하면 청구가 자동 생성됩니다. 금액은 서비스 유형·등급·시간으로 자동 계산됩니다.
본인부담금자동 계산승인된 청구에서 계산됩니다. 사람이 입력하는 것은 수납 여부뿐입니다.
급여 계산자동 계산승인된 청구와 직원별 급여 비율로 계산됩니다. 센터장은 확정만 합니다.
평가 준비 자료·제공기록지자동 취합방문 기록·평가·상담에서 모아 보여 주며, 따로 입력하지 않습니다.
방문 기록 현황 ↔ 청구관리같은 데이터를 두 화면에서 봄입력이 두 번이 아니라 보는 화면이 둘입니다. 승인은 청구관리 한 곳에서만 합니다.
도착·퇴실 ↔ 음성 기록의 방문 시간자동 연결도착·퇴실을 눌렀다면 음성 기록에 도착 시각이 방문 일시로, 도착~퇴실 시간이 가장 가까운 제공 시간(30·60·90분…)으로 미리 채워집니다. 버튼을 누르지 않았다면 직접 입력합니다.
보호자 정보두 곳에 존재이용자 정보의 "보호자 이름·연락처"(참고용)와, 보호자가 직접 가입한 계정이 따로입니다. 서로 자동으로 맞춰지지 않습니다. (개선 후보)
공단 전자태그(스마트장기요양 앱) ↔ 돌봄케어 기록이중 입력 남음공단 앱은 서비스 종료 전송 때 제공 내용(항목별 분 단위)·변화 상태·특이사항·서명을 입력하게 합니다. 돌봄케어는 아직 공단과 연동되어 있지 않아 같은 내용을 두 곳에 적어야 할 수 있습니다. (공단 문의 중)
승인 단계의도된 확인 3단계방문 계획 승인 → 청구 승인 → 급여 확정은 서로 다른 것을 확인합니다(미리 정한 일정 / 실제 제공한 서비스 / 월 급여). 같은 것을 두 번 승인하는 것이 아닙니다.
요양보호사의 "제출"추가 1단계기록 저장과 별도로 "나의 청구"에서 제출해야 센터장에게 올라갑니다. 기록 후 한 번 더 확인하게 하려는 단계입니다.
