# 돌봄케어 청부관리 시스템 - 감사 보고서

**감사일**: 2026-10-01

## 🔴 발견된 문제점

### 1. Frontend 통계 카드 (4개) vs 필터 버튼 (8개) 불일치
- **현재 상태**: 통계 카드는 4개(전체, 대기중, 승인, 거절)만 표시
- **필터 버튼**: 8개 (전체, 대기중, 승인, 건보청구, 환급확정, 환급완료, 거절된건보, 거절)
- **문제**: 존재하지 않는 상태("환급확정", "거절된건보") 필터가 있음
- **영향**: 사용자가 필터를 클릭해도 데이터가 안 나옴

### 2. 아카이브 탭 전환 시 통계 업데이트 누락
- **현재**: `switchTab()` 함수가 탭만 전환하고 통계를 업데이트하지 않음
- **문제**: "현재 청부" vs "아카이브된 청부" 탭 전환 시 통계 숫자가 변하지 않음
- **영향**: 사용자가 혼동함 (총 4개 → 아카이브 탭에서도 4개?)

### 3. Backend 상태 정의 불명확
**현재 정의 상태들:**
- `pending` - 승인 대기
- `approved` - 승인됨
- `submitted_to_nhis` - 건보 청구됨
- `confirmed` - 확정됨 (미사용)
- `rejected_by_nhis` - 건보 거절 (미사용)
- `reimbursed` - 환급완료 (아카이브)
- `rejected` - 거절됨

**미사용 상태들:** `confirmed`, `rejected_by_nhis`

### 4. 필터 버튼의 상태 이름과 실제 DB 값 불일치
```
버튼: "환급확정" ← → DB: "confirmed" (데이터 없음)
버튼: "건보 반려" ← → DB: "rejected_by_nhis" (데이터 없음)
```

### 5. API 응답 필드 누락
- **현재**: `reimbursed_amount`, `reimbursement_date` 등의 고급 필드 없음
- **영향**: 환급 관련 통계를 상세히 표시할 수 없음
