🚀 Hetzner 가입 & 배포 (3단계, 30분)

Step 1: Hetzner 계정 생성 (5분)

  • 사이트: https://www.hetzner.com/cloud
  • 회원가입: 이메일 + 신용카드
  • 첫 결제: €3 (약 ₩4,000)
  • 혹시 USD로 표시되면 신용카드 국가 설정 확인

Step 2: 서버 생성 (10분)

  • Hetzner 대시보드 → Servers → Create Server
  • Location: Falkenstein (독일) 선택
  • Image: Ubuntu 22.04
  • Type: CPX11 (₩4,000/월) - 추천
  • SSH Key: 새로 생성 또는 기존 키 업로드
  • Create 클릭

CPX11 = 1 vCPU, 1GB RAM, 25GB SSD (€3)

Step 3: FastAPI + PostgreSQL 배포 (15분)

Step 3-1: 서버에 접속

ssh -i ~/.ssh/id_rsa root@your-server-ip

Step 3-2: 기본 패키지 설치

apt update && apt upgrade -y
apt install -y python3.11 python3-pip postgresql postgresql-contrib nginx git

Step 3-3: PostgreSQL 설정

sudo -u postgres psql
CREATE DATABASE dolbomcare_db;
CREATE USER dolbomcare WITH PASSWORD 'your_password';
ALTER ROLE dolbomcare SET client_encoding TO 'utf8';
ALTER ROLE dolbomcare SET default_transaction_isolation TO 'read committed';
GRANT ALL PRIVILEGES ON DATABASE dolbomcare_db TO dolbomcare;
\q

Step 3-4: FastAPI 배포

# 프로젝트 클론
git clone https://github.com/your-repo/dolbomcare.git
cd dolbomcare/backend

# 의존성 설치
pip install -r requirements.txt

# FastAPI 백그라운드 실행
nohup uvicorn main:app --host 0.0.0.0 --port 8000 > /var/log/dolbomcare.log 2>&1 &

Step 3-5: Nginx 리버스 프록시 설정

sudo nano /etc/nginx/sites-available/default

# 다음을 추가:
server {
    listen 80;
    server_name your-domain.com;  # 또는 IP 주소

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

# 저장 후:
sudo systemctl restart nginx

Step 3-6: SSL 인증서 (Let's Encrypt)

apt install certbot python3-certbot-nginx -y
certbot --nginx -d your-domain.com

✅ 완료! 브라우저에서 확인: http://your-server-ip
