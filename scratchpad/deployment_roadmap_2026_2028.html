🚀 돌봄케어(Dolbomcare) 배포 로드맵 2026-2028

한국 요양관리 플랫폼(케어포, 이지케어) + 국제 케어 플랫폼(AxisCare, ShiftCare) 분석을 바탕으로 한 MVP → 전국 확대 3단계 배포 전략

📍 PHASE 1: MVP 파일럿 (2026년 6-9월) - 서울 1개 센터

✅ 목표

  • 1개 센터에서 완전 운영: 요양사 20-30명, 이용자 50-100명
  • 핵심 기능 검증: 로그인 → 일정 관리 → 청부 기록 → 급여 정산
  • 운영 프로세스 정립: 기술 지원, 데이터 보안, 규정준수
  • 초기 고객 확보 (Reference customer): 추후 마케팅의 9.2배 채택률 향상

⚡ 기술 스택 (국제 플랫폼 표준)

클라우드 인프라
  • AWS Seoul Region (ap-northeast-2)
  • RDS PostgreSQL 15 (자동 백업)
  • Auto Scaling (요청 증가 시)
  • CloudFront CDN (모바일 앱 배포)
보안 & 규정준수
  • SSL/TLS 암호화
  • 개인정보 암호화 저장 (AES-256)
  • 접근 제어 (RBAC)
  • 감사 로그 (audit trail)

🎯 파일럿 센터 선정 기준

  • Location: 서울 강남/서초/송파 (기술 지원 접근성)
  • Size: 20-30명 요양사 (조직 구조 복잡하지 않음)
  • Tech-savviness: 센터장이 새로운 기술 개방적
  • Pain point: 현재 수작업 급여/청부 관리 (명확한 ROI)
  • Commitment: 4개월 집중 사용 약속 + 피드백

📅 타임라인

6월 (4주)

센터 선정 & 계약

  • 5-10개 센터 인터뷰
  • 서비스 레벨 협정(SLA) 작성
  • 기술 지원 팀 배치

7월 (4주)

구현 & 온보딩

  • 데이터 마이그레이션
  • 스태프 훈련 (3일)
  • 시스템 안정화

8월 (4주)

운영 & 버그 수정

  • 일일 지원
  • 피드백 수집
  • 기능 개선

9월 (4주)

성과 검증 & 다음 단계 계획

  • ROI 측정
  • 케이스 스터디 작성
  • Phase 2 준비

💰 예상 비용

  • AWS 클라우드: ~₩150만/월 (서버, DB, 대역폭)
  • 보안 인증: ISO 27001 사전심사 ~₩300만
  • 인력: 기술 지원 담당자 1명, 개발자 0.5명 (지속 개선)
  • 합계 Phase 1: ~₩800만 (4개월)
✅ Phase 1 성공 지표
  • 일 가용성 99% 이상
  • 센터 만족도 4.5/5.0 이상
  • 기능 사용률 80% 이상 (일정관리, 청부 기록)
  • 운영 비용 30% 절감 (대비 수작업)

🌍 PHASE 2: 지역 확대 (2026년 10월 - 2027년 3월) - 서울 + 경기 20개 센터

✅ 목표

  • 고객 규모: 20개 센터 (요양사 400-500명, 이용자 1,000-1,500명)
  • 지역: 서울 (기축) + 경기도 (인접)
  • 마케팅 채택: Phase 1 파일럿 센터를 Reference 고객으로 활용 (9.2배 효과)
  • 기술 성숙도: 자동화된 배포 파이프라인, 기술 지원 체계 확립

📊 마케팅 전략 (한국 업체 분석)

  • 직접 영업: 한국 요양사협회, 센터 협회 파트너십 (케어포, 이지케어 사례)
  • Reference 고객: Phase 1 센터 방문 후기 + ROI 사례
  • 온라인: 블로그 (급여/청부 계산 가이드), YouTube (기능 데모)
  • 제휴: 회계/세무 사무소 (급여정산 자동화 추천)
  • 판매 사이클: 평균 125일 (영업) + 8-10주 (구현) = 6-8개월

📅 실행 타임라인

기간 마일스톤 주요 활동
10월 (4주) 고객 확보 시작 요양사협회 MOU 체결, 영업팀 구성, 가격 정책 결정
11-12월 (8주) 5-10개 센터 영업 데모, 계약 체결, 데이터 마이그레이션 계획
1월 (4주) 구현 가속화 4-5개 센터 동시 온보딩, 기술 지원팀 확대
2월 (4주) 기존 고객 최적화 Phase 1-2 고객 안정화, 피드백 수집, 기능 개선
3월 (4주) 검증 & 확대 준비 16개 센터 운영 중, Phase 3 전략 수립

💰 예상 비용 & 수익

운영 비용

  • AWS 클라우드: ~₩400만/월 (20개 센터, 더 많은 데이터)
  • 인력: 영업 2명, 기술 지원 2명, 개발 1명
  • 마케팅: ₩200만/월 (온라인, 협회 활동)
  • 월 운영 비용: ~₩1,500만

예상 매출

  • 가격 정책: 센터당 ₩300만-500만/월 (요양사 수, 기능 기준)
  • 평균 20개 센터 × ₩400만 = ₩8,000만/월
  • 연간 예상: ~₩9.6억 (4개월 6개월분 계산)
⚠️ Phase 2 주요 위험
  • 판매 사이클 연장: 계획보다 영업이 느릴 수 있음 → 초기 목표를 10개로 낮추고 3개월 후 평가
  • 기술 지원 부족: 빠른 확대로 고객 만족도 하락 → 기술 지원 팀 사전 확대 필수
  • 경쟁사 응전: 케어포, 이지케어가 기능 강화 → 차별점 강조 (한국식 급여 정산, 청부 워크플로우)
  • 데이터 보안 문제: 개인정보 유출 사건 시 이미지 손상 → ISO 27001 인증 완료 필수

🗺️ PHASE 3: 전국 확대 & 생태계 (2027년 4월 - 2028년) - 전국 150-200개 센터

✅ 목표

  • 고객 규모: 150-200개 센터 (요양사 3,000-4,000명, 이용자 10,000명+)
  • 지역: 서울 → 경기 → 인천 → 부산/대구/대전 (인구 밀도 순)
  • 생태계: 의료기관 연계, 보호자 앱, 자동 청구 시스템
  • 수익: 월 ₩50억+ (종속 기업 전환 가능 규모)

🏥 의료기관 & 정부 연계

한국 케어포, 이지케어의 경우 정부 의료정보화 사업(2026년 통합 돌봄 시스템)과 연계되어 전국 확대 달성

  • 정부 지원: 보건복지부 "통합 돌봄" 시범사업 참여 (30개 지자체)
  • 요양기관 인증: 대한요양기관협회 표준 시스템 인정
  • 의료 데이터 연계: 건강보험심사평가원 청구 시스템 직연
  • 보호자 앱: iOS/Android 독립 앱 (이용자 상태 실시간 공유)

🔒 기술 & 규정준수 로드맵 (병렬 진행)

보안 인증 (전체 3단계)

인증 완료 시기 비용 필요성
ISO 27001 (정보보안) 2026년 9월 (Phase 1 후) ₩500만-1,000만 필수 (고객 신뢰)
ISMS 인증 (한국) 2027년 3월 (Phase 2 후) ₩300만 필수 (정부 계약)
개인정보보호 심사 2026년 8월 (지속) ₩200만/년 필수 (법령)

기술 인프라 진화

  • Phase 1: 단일 AWS 리전 (Seoul), RDS PostgreSQL, Auto Scaling 기본
  • Phase 2: 다중 가용 영역 (AZ), 읽기 복제본, CDN 확대
  • Phase 3: 재해 복구 체계 (DR 리전), 실시간 분석 (DMS → Redshift), 마이크로서비스 전환

국제 진출 준비 (선택사항)

  • 일본: 간호사 기록 법규 다름 (2027년)
  • 싱가포르: 영어 지원 + PDPA 준수 (2028년)
  • 동남아: 현지화된 급여 정산 로직
