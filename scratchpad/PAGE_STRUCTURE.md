# 돌봄케어 페이지 구조 차별화

## 1️⃣ 나의 청부 (caregiver_billing.html)
**대상**: 요양사
**목적**: 자신의 청부 상태 조회 및 수정

### 주요 기능
- ✅ 자신의 청부만 표시
- ✅ 제출 (draft → pending)
- ✅ 수정 (거절 후)
- ✅ 삭제 (draft 상태만)

### UI 특징
- 색상: 초록색(#10b981) + 파란색(#3b82f6)
- 테이블: 4열 (기록일, 이용자, 서비스, 금액, 상태)
- 액션: [제출], [수정], [삭제]
- 통계: 대기, 승인, 거절 (자신의 것만)

### 화면 구성
```
📊 나의 청부
"요양 활동 청부 상태 확인"
┌─────────────────────┐
│ 전체 4건 | 대기 1건 │
│ 승인 2건 | 거절 1건 │
└─────────────────────┘
[필터: 전체 | 대기 중 | 승인됨 | 거절됨]
┌────────────────────────────────┐
│ 테이블 (자신의 청부만)         │
│ [제출] [수정] [삭제] 버튼     │
└────────────────────────────────┘
```

## 2️⃣ 청부 관리 (billing_management.html)
**대상**: 센터장 (관리자)
**목적**: 모든 청부 승인/거절/관리

### 주요 기능
- ✅ 모든 요양사의 청부 표시
- ✅ 승인 (pending → approved)
- ✅ 거절 (pending → rejected + 사유)
- ✅ 상세 조회
- ✅ 통계 및 분석

### UI 특징
- 색상: 주황색(#f59e0b) + 빨강색(#ef4444)
- 테이블: 7열 (날짜, 요양사, 이용자, 서비스, 금액, 상태, 관리)
- 액션: [승인], [거절], [상세조회]
- 통계: 전체, 대기, 승인, 거절 (모든 것)

### 화면 구성
```
📋 청부 관리
"전체 청부 현황 및 승인 관리"
┌──────────────────────────┐
│ 전체 145건 | 대기 23건  │
│ 승인 98건 | 거절 24건   │
└──────────────────────────┘
[필터: 전체 | 대기 중 | 승인 | 거절]
[검색: 요양사명, 이용자명]
[정렬: 날짜, 금액, 상태]
┌────────────────────────────────┐
│ 테이블 (모든 청부)             │
│ [승인] [거절] [상세] 버튼      │
└────────────────────────────────┘
```
