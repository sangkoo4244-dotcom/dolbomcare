🟢 Option 1: Oracle Cloud Free Tier (가장 추천)

가입 및 설정 (5단계, 30분)

Step 1: Oracle Cloud 가입

사이트: https://www.oracle.com/cloud/free

  • 회원가입 (이메일 + 신용카드)
  • 신용카드로 결제 여부 확인 안 됨 (정말 무료)
  • 계정 활성화 (10분 소요)

Step 2: Compute Instance 생성

Oracle Cloud Console → Compute → Instances

  • Image: Ubuntu 22.04 LTS
  • Shape: VM.Standard.E2.1.Micro (2 vCPU, 1GB RAM)
  • Storage: 50GB Boot Volume
  • 네트워크: VCN (Virtual Cloud Network) 생성
  • SSH 키: 다운로드 후 안전히 저장

Step 3: Autonomous Database PostgreSQL 생성

Oracle Cloud Console → Database → Autonomous Database

  • DB 이름: dolbomcare_db
  • 사용자: admin (기본값)
  • 비밀번호: 안전한 비밀번호 설정
  • 무료 정보: 20GB 저장소 (파일럿 충분)

Step 4: FastAPI 배포

서버에 SSH로 접속

ssh -i your-key.key ubuntu@your-instance-ip

# Python 설치
sudo apt update && sudo apt install -y python3.11 python3-pip

# 프로젝트 클론
git clone https://github.com/your-repo/dolbomcare.git
cd dolbomcare/backend

# 의존성 설치
pip install -r requirements.txt

# FastAPI 실행 (백그라운드)
nohup uvicorn main:app --host 0.0.0.0 --port 8000 > app.log 2>&1 &

Step 5: 보안 그룹 설정

인바운드 트래픽 허용

  • 포트 22 (SSH)
  • 포트 80 (HTTP)
  • 포트 443 (HTTPS)
  • 포트 8000 (FastAPI)

예상 성능

  • 요청 처리: 1-2개 센터 (동시 10-20명 사용자) 충분
  • 응답 속도: 200ms+ (한국에서 싱가포르 거리)
  • 안정성: 99.5% (Oracle SLA)

❓ 자주하는 질문

Q1: Oracle Cloud 정말 무료인가요?

✅ 네, 완전 무료입니다. 신용카드는 신원 확인용이고, 결제되지 않습니다. (12개월 기본 + 평생 무료 요금제)

Q2: 센터 담당자가 느리다고 불평하면?

⚠️ Oracle Cloud는 싱가포르/도쿄에 있어 한국에서 200ms 지연이 발생합니다.
파일럿이 성공하면 AWS Lightsail (Seoul)로 마이그레이션하면 됩니다. (1시간 소요)

Q3: 개인정보 법적 문제는 없나요?

⚠️ 주의! Oracle Cloud (해외 서버)는 한국 개인정보보호법 적용이 모호합니다.
실제 센터와 계약하려면 AWS Lightsail (Seoul)로 마이그레이션 필수 (₩100만/월).

Q4: 데이터 백업은 어떻게?

✅ Oracle Cloud Autonomous Database는 자동 일일 백업이 포함되어 있습니다.
추가로 pg_dump로 수동 백업 가능합니다.
