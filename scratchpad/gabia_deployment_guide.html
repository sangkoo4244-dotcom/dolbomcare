  • 이메일로 서버 접속 정보 받음
  • IP 주소, SSH 포트, 루트 비밀번호 저장

Step 2: 서버에 SSH로 접속 (5분)

Windows 또는 Mac에서

터미널 열기

ssh root@your-server-ip -p 22
# 비밀번호 입력

또는 (더 안전함)

ssh -i ~/.ssh/id_rsa root@your-server-ip

💡 Tip: 가비아에서 받은 접속 정보에 포트 번호가 다를 수 있음 (예: 22 대신 2222)
메일에서 정확한 포트 번호 확인 필수!

Step 3: 기본 설정 (10분)

3-1. 시스템 업데이트

apt update && apt upgrade -y

3-2. 필수 패키지 설치

apt install -y python3.11 python3-pip postgresql postgresql-contrib nginx git curl

3-3. Python 버전 확인

python3 --version
pip3 --version

3-4. 가비아 방화벽 설정

  • 가비아 콘솔 접속
  • VPS 관리 → 보안 그룹
  • 포트 개방: 22 (SSH), 80 (HTTP), 443 (HTTPS), 8000 (FastAPI)

Step 4: PostgreSQL 설정 (10분)

4-1. PostgreSQL 시작

sudo systemctl start postgresql
sudo systemctl enable postgresql

4-2. 데이터베이스 생성

sudo -u postgres psql
CREATE DATABASE dolbomcare_db;
CREATE USER dolbomcare WITH PASSWORD 'your_strong_password';
ALTER ROLE dolbomcare SET client_encoding TO 'utf8';
ALTER ROLE dolbomcare SET default_transaction_isolation TO 'read committed';
GRANT ALL PRIVILEGES ON DATABASE dolbomcare_db TO dolbomcare;
\q

4-3. .env 파일 생성

nano ~/.env
# 다음 내용 입력:
DATABASE_URL=postgresql://dolbomcare:your_password@localhost:5432/dolbomcare_db
SECRET_KEY=your-secret-key-very-long-string
DEBUG=False
ENVIRONMENT=production

Step 5: FastAPI 배포 (15분)

5-1. 프로젝트 클론

cd /var/www
git clone https://github.com/your-username/dolbomcare.git
cd dolbomcare/backend

5-2. 의존성 설치

pip install -r requirements.txt

5-3. Supervisor 설정 (자동 시작)

sudo nano /etc/supervisor/conf.d/dolbomcare.conf

다음 내용 입력:

[program:dolbomcare]
directory=/var/www/dolbomcare/backend
command=/usr/bin/python3 -m uvicorn main:app --host 0.0.0.0 --port 8000
autostart=true
autorestart=true
stderr_logfile=/var/log/dolbomcare.err.log
stdout_logfile=/var/log/dolbomcare.out.log
user=root

5-4. Supervisor 시작

sudo systemctl start supervisor
sudo systemctl enable supervisor
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start dolbomcare

5-5. 상태 확인

sudo supervisorctl status dolbomcare
# 출력: dolbomcare RUNNING pid 1234, uptime 0:00:05

Step 6: Nginx 설정 (포트 8000 → 80) (10분)

6-1. Nginx 설정 파일 편집

sudo nano /etc/nginx/sites-available/default

다음 내용으로 교체:

server {
    listen 80 default_server;
    listen [::]:80 default_server;
    server_name _;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

6-2. Nginx 재시작

sudo systemctl restart nginx
sudo systemctl enable nginx

6-3. 상태 확인

sudo systemctl status nginx

Step 7: SSL 인증서 (무료 Let's Encrypt) (5분)

7-1. Certbot 설치

sudo apt install certbot python3-certbot-nginx -y

7-2. 인증서 발급

sudo certbot --nginx -d your-domain.com

💡 도메인이 없으면?
- 가비아에서 도메인 구매 (연간 ₩5,000-30,000)
- 또는 IP 주소로 직접 접속 (https://your-ip:443)

7-3. 자동 갱신 설정

sudo systemctl enable certbot.timer
sudo systemctl start certbot.timer

🆘 문제 해결

Q1: FastAPI가 시작 안 됨

해결:

sudo supervisorctl restart dolbomcare
sudo supervisorctl tail dolbomcare  # 로그 확인

Q2: 데이터베이스 연결 실패

해결:

.env 파일에서 DATABASE_URL 확인
psql -U dolbomcare -d dolbomcare_db  # 연결 테스트

Q3: Nginx가 연결 못 함

해결:

sudo systemctl restart nginx
sudo systemctl status nginx  # 상태 확인
sudo tail -f /var/log/nginx/error.log  # 에러 로그

Q4: 방화벽 포트 막혔을 때

해결:

  • 가비아 콘솔 → VPS 관리 → 보안 그룹
