🚀 Railway로 배포하기 (가장 쉬운 방법)

유튜브에서 가장 많이 추천하는 방식
GitHub에 Push → 자동 배포 (5분 내)

Step 1: Railway 가입 (2분)

  • 사이트: https://railway.app
  • GitHub로 로그인
  • Dashboard 확인

Step 2: 프로젝트 생성 (3분)

  • GitHub 저장소 연결
  • 자동 감지: FastAPI 인식
  • "Deploy Now" 클릭

Step 3: 환경 변수 설정 (2분)

Railway Dashboard → Environment Variables

DATABASE_URL=postgresql://user:pass@db:5432/dolbomcare_db
SECRET_KEY=your-secret-key
DEBUG=False

Step 4: PostgreSQL 추가 (2분)

  • Railway Dashboard → Add Service → PostgreSQL
  • 자동으로 DATABASE_URL 생성됨
  • DB가 자동 연결됨

✅ 완료!

브라우저에서 확인: https://your-app.railway.app

이제 GitHub에 Push하면 자동으로 배포됨!
