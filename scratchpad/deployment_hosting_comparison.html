🏆 추천 Top 3

1️⃣ 네이버 클라우드 ⭐⭐⭐⭐⭐ (최고 추천)

월 ₩150-200만

제공 기능:

  • Server: Linux VM (vCPU 2, RAM 4GB) = ₩50만/월
  • Database: PostgreSQL 15 관리형 DB = ₩60-80만/월
  • Frontend: CDN (무료 or ₩20만/월)
  • Backup: 자동 일일 백업 (포함)
  • SSL/TLS: 무료 인증서

✅ 장점:

  • 한국 서버 = 초저지연 (1ms 이내)
  • 24시간 한국 기술지원 (전화 지원)
  • 한국 법인/센터가 이용 중 (신뢰도 높음)
  • 요양 데이터 = 한국 서버 저장 (GDPR/개인정보보호법 준수)
  • 정부/금융 클라우드 기준 충족 (ISO 27001 사전구성)
  • 초기 스타트업 할인 가능 (문의하면 20-30% 할인)

❌ 단점:

  • AWS보다 문서 적음 (하지만 한국 기술 블로그 풍부)
  • 스케일링이 AWS보다 제한적 (하지만 Phase 1-2에는 충분)

필요 서버 사양 (Phase 1):

CPU2 vCore
메모리4GB RAM
디스크100GB SSD
대역폭1Gbps (무제한)

🎯 설정:

  • FastAPI uvicorn 데몬 + Supervisor 자동 재시작
  • Nginx 리버스 프록시 (포트 8000 → 80/443)
  • PostgreSQL 자동 백업 (일 1회)
  • cron: 매일 03:00 자동 재부팅 (메모리 누수 방지)
💡 추천 이유: 한국 기업/센터가 이용하는 시스템이고, 기술지원이 한국어로 가능하며, 초기 규모(1-2개 센터)에 완벽함. Phase 2로 확대할 때도 비용 증가가 적음.

2️⃣ 카카오 클라우드 ⭐⭐⭐⭐⭐ (비용 최저)

월 ₩100-150만

제공 기능:

  • Server: Linux VM (vCPU 2, RAM 4GB) = ₩40만/월
  • Database: PostgreSQL 관리형 = ₩50-60만/월
  • Frontend: CDN (₩10-20만/월)
  • 특징: 신용카드 결제 시 10% 추가 할인

✅ 장점:

  • 가장 저렴한 비용 ⭐
  • 한국 서버 (카카오 인프라 신뢰도 높음)
  • 한국 기술지원
  • 신용카드 결제 시 추가 할인
  • 초기 3개월 트라이얼 가능

❌ 단점:

  • 네이버보다 시장 점유율 낮음 (신뢰도 약간 낮음)
  • UI/문서가 네이버보다 복잡함
  • 기술지원이 네이버보다 느림 (이메일 중심)
💡 추천 이유: 비용이 최저이고, Phase 1 파일럿에서 비용을 최소화하려면 최고의 선택. 나중에 네이버로 마이그레이션 가능.

3️⃣ AWS Lightsail ⭐⭐⭐ (중간 추천)

월 ₩300만+ (비싼 편)

제공 기능:

  • 서버: $10-40/월 (VPS 호스팅 대체)
  • Database: 별도 구성 필요

✅ 장점:

  • AWS 생태계 (향후 확장성 좋음)
  • 현재 이미 사용 중 (마이그레이션 불필요)

❌ 단점:

  • 네이버/카카오보다 2-3배 비쌈
  • 한국 지원 제한적 (영문 위주)
  • 초보자 친화적이 아님
  • 한국 의료법/개인정보 담당자가 검증하기 어려움
💡 추천 이유: 지금 AWS를 쓰고 있다면 유지해도 되지만, 새로 시작한다면 네이버/카카오가 더 나음.

⚠️ 절대 피하기

❌ Railway, Render, Vercel, Replit

왜 안 되는가:

  • 불안정한 요금제: 사용량 초과하면 갑자기 청구 (한 달에 ₩500만+ 가능)
  • 데이터 센터가 미국: 지연 시간 높음 (100-200ms) → 모바일 앱 반응성 나쁨
  • 한국 의료법 미준수: 개인정보 해외 저장 금지 가능
  • 기술지원 없음: 커뮤니티 포럼만 가능
  • Heroku 종료: Railway/Render도 시간 문제 (불안정)

❌ 가비아 (낮은 등급 호스팅)

왜 안 되는가:

  • Linux 호스팅은 FastAPI 배포 어려움 (PHP/Node 중심)
  • PostgreSQL 관리가 불편함
  • 확장성 제한 (크기 커지면 업체 변경 필수)
  • 기술지원이 웹 호스팅 수준 (개발자 지원 약함)

📝 네이버 클라우드 구체적 설정

Step 1: 서버 구성

상품명 Standard vServer
사양 vCPU 2, Memory 4GB, SSD 100GB
OS Ubuntu 22.04 LTS
위치 Seoul Region (ap-southeast-1)
월 비용 ₩50-80만

설치할 소프트웨어:

  • Python 3.11 + pip
  • FastAPI + uvicorn
  • Nginx (리버스 프록시)
  • Supervisor (프로세스 관리)
  • PostgreSQL 15 (클라이언트만 - DB는 관리형 사용)
  • Git + GitHub 연동 (자동 배포)

Step 2: Database 구성

상품명 Cloud DB for PostgreSQL
버전 PostgreSQL 15
사양 고가용성 (Master-Slave) 구성
백업 자동 일일 백업 (30일 보관)
월 비용 ₩60-100만

보안 설정:

  • SSL 연결 필수
  • VPC 내부 통신만 허용 (외부 접근 차단)
  • 자동 백업 + 포인트 인타임 복구 (PITR) 활성화

Step 3: Frontend 배포

  • HTML/CSS/JS 파일: Nginx 서버에서 직접 서빙
  • 모바일 앱 (React Native): Expo 또는 AppStore/PlayStore 배포
  • CDN (선택): 나중에 필요하면 네이버 CDN (₩20만/월)

Step 4: 배포 파이프라인

GitHub → Webhook → 네이버 클라우드 자동 배포

1. GitHub에 push
2. Webhook 트리거
3. 서버에서 git pull
4. pip install -r requirements.txt
5. systemctl restart dolbomcare (FastAPI 재시작)
6. 무중단 배포 (Supervisor 관리)
