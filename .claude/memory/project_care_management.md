# 요양관리 프로그램 개발 프로젝트

## 프로젝트 목표
2026년 한국 요양관리 시장에 진입하여 차별성 있는 요양관리 플랫폼 개발 및 상용화

## 시장 기회 (2026년 기준)

### 시장 규모
- 재가돌봄 시장: 65.82억 USD (2026년) → 133.24억 USD (2033년)
- 연평균 성장률: 10.6% CAGR
- 주 동인: 고령화 심화, 요양급여 확대, 정책 지원

### 정책 지원 환경
- 요양급여 한도액 인상 (지속적)
- 통합돌봄지원법 시행 (2026년 3월)
- 요양사 처우개선 정책
- 원격의료 정식화

### 기술 기회
- AI 헬스케어: 50.8% 성장세
- 원격모니터링 법제화
- 클라우드 기반 EHR 증가
- 웨어러블 기기 통합

## 경쟁 환경

### 주요 플레이어
1. **케어링** (직영 방식)
   - 매출: 약 1,200억원
   - 특징: 직영 센터 기반, 통합 요양서비스
   
2. **케어네이션** (매칭 플랫폼)
   - 다운로드: 47만 이상
   - 특징: 요양사-기관 매칭, 앱 중심
   
3. **보살핌** (워크포스)
   - 상태: 연 흑자 달성
   - 특징: 요양사 관리, 급여 시스템

### 기존 솔루션의 한계
- 기록 위주의 시스템 (의사결정 지원 부족)
- 의료기관과의 연계 미흡
- 보호자 신뢰도 낮음
- 요양사 독립성 제약

## 차별화 전략

### 핵심 가치 제안
1. **기록 → 의사결정 지원 시스템**
   - AI 기반 케어 예측 및 권고
   - 예방적 개입 중심

2. **요양사 독립성 강화**
   - 수수료 기반 플랫폼 (강압적 통제 최소화)
   - 선택의 자유도 높음

3. **의료 연계**
   - 병원-요양원-재가 통합 EHR
   - HL7 표준 호환성

4. **보호자 신뢰**
   - 실시간 모니터링 & 투명성
   - 정기 리포팅 자동화

## 독립성 전략

### 기술 독립성
- 오픈소스 우선 (DB: PostgreSQL, 백엔드: Django/FastAPI)
- 자체 데이터 아키텍처
- 클라우드 멀티테넌시 (AWS/GCP 비종속)

### 데이터 독립성
- API 개방화 (사용자 데이터 포팅 용이)
- 표준 포맷 (HL7, FHIR)
- 상호운용성 확보

### 비즈니스 독립성
- 다중 수익원 (SaaS + API + 분석 + 교육)
- 플랫폼 의존도 최소화
- 지리적 확장 (한국 → 아시아)

## 수익 모델

### 기본 수익 (SaaS)
- **요양센터당**: 월 200-500만원 (규모별)
- **사용자당**: 월 50-100만원 (요양사, 관리자)
- **기능별**: 프리미�m 기능 추가 요금

### 추가 수익원
1. **API 접근료**: 외부 연계 기관당 월 100-300만원
2. **데이터 분석**: 거주자 건강 리포트 월 50-100만원
3. **교육 & 컨설팅**: 요양사 교육 과정 연 500만원+
4. **의료 연계**: 병원 추천 및 데이터 공유 수수료

### 수익성 목표
- **ARPU**: 기본 200만원 → 600-700만원 (3배)
- **마진율**: 35-50% (일반 SaaS 수준)
- **손익분기점**: 월 50개 센터 (약 1-1.5년)

## 실행 로드맵

### Phase 1: MVP (0-6개월)
**목표**: 핵심 기능 검증 & 초기 고객 확보
- 기능: 요양사 관리, 기본 케어 기록, 의약품 관리, 보호자 앱 (4가지)
- 기관: 50개 센터 (테스트)
- 기술: MVP 스택 구성, 데이터 보안
- 산출: 제품-시장 적합성 확인

### Phase 2: 상용화 (6-12개월)
**목표**: 수익성 있는 상용 운영
- 기능: AI 예측 추가, 의료 연계 (부분)
- 기관: 50개 → 100개 센터
- 고객확보: 직영 영업팀 구성
- 수익: 월 3-5억원 (50개 센터 × 300-500만원)

### Phase 3: 확장 (12-24개월)
**목표**: 전국 주요 센터 확보
- 기능: 통합 EHR, 완벽한 의료 연계, 데이터 분석 플랫폼
- 기관: 300개 센터 확대
- 마케팅: 요양관련 협회, 보험사 파트너십
- 수익: 월 20-30억원 예상

## 핵심 성공 요소

✅ **빠른 제품-시장 적합성 검증** (3개월)
✅ **고객 만족도 높은 UX** (직관적, 번거로움 최소)
✅ **규제 준수 철저** (PIMS, ISMS-P, 개인정보보호)
✅ **의료기관과의 파트너십** (병원 추천 루트)
✅ **요양사 커뮤니티 구축** (입소문 확산)

## 필수 규제 준수

- **PIMS** (의료기기 소프트웨어 관리): 클래스 2 (의료기기 인증)
- **ISMS-P**: 정보보안 관리체계 인증 필수
- **개인정보보호법**: 건강정보 처리 규정 준수
- **HL7/FHIR**: 의료 데이터 표준 호환성
- **EMR 인증**: 필요시 전자의무기록 인증
