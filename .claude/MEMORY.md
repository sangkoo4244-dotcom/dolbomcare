## 요양관리 프로젝트 Context

### 프로젝트 목표
2026년 한국 요양관리 시장에 진입하여 차별성 있는 요양관리 플랫폼 개발 및 상용화

### 시장 기회 (2026년 기준)
- 재가돌봄 시장: 65.82억 USD (2026년) → 133.24억 USD (2033년)
- 연평균 성장률: 10.6% CAGR
- 정책 지원: 요양급여 인상, 통합돌봄지원법(2026년 3월), 원격의료 정식화

### 주요 경쟁사
1. **케어링** - 직영 방식, 매출 1,200억원
2. **케어네이션** - 매칭 플랫폼, 47만 다운로드
3. **보살핌** - 워크포스 중심, 연 흑자

### 차별화 전략
- 기록 도구 → **의사결정 지원 시스템** (AI 기반 예측)
- **요양사 독립성 강화** (수수료 기반)
- **의료기관 연계** (통합 EHR)
- **보호자 신뢰** (실시간 모니터링)

### 독립성 전략
- 오픈소스 우선 (PostgreSQL, Django/FastAPI)
- API 개방화 (HL7, FHIR 표준)
- 다중 수익원 (SaaS + API + 분석 + 교육)

### 수익 모델
- **기본**: SaaS 구독 (월 200-500만원/기관당)
- **추가**: API 접근료, 데이터 분석, 교육, 의료 연계 수수료
- **목표 ARPU**: 200만원 → 600-700만원 (3배)
- **마진율**: 35-50%

### 실행 로드맵
```
Phase 1 (0-6개월):  MVP → 50개 센터 테스트
Phase 2 (6-12개월): 상용화 → 100개 센터, 월 3-5억원
Phase 3 (12-24개월): 확장 → 300개 센터, 월 20-30억원
```

### 필수 규제 준수
- PIMS (의료기기 소프트웨어 인증)
- ISMS-P (정보보안 관리체계)
- 개인정보보호법 (건강정보 처리)
- HL7/FHIR 표준 호환성

## 무자본 + 1명 스타트트업 실행 전략

### 현황
- 자본: 0원
- 팀: 1명 (혼자)
- 목표: 6개월 내 고객 검증 + 자금 확보 (3-5억원)

### 실행 단계

**Phase 0 (지금-2개월): 검증**
- 고객 인터뷰 30-50명 (4주)
- 무료 프로토타입 8개 화면 (Figma, 2주)
- K-스타트업 신청 준비 (동시진행)

**Phase 1 (2-4개월): 자금 확보 + MVP 개발**
- K-스타트업 1억원 선정
- 초기창업패키지 신청 (월 300만원 × 12개월)
- MVP 개발 시작 (3개 기능만)

**Phase 2 (4-6개월): 파일럿 + 투자**
- 파일럿 5개 센터 무료 운영
- 초기 월 2-3억원 매출 목표
- Series A 준비
